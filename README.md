**By:** Mahrukh Baloch - BSIT MNSUAM Multan
**Internship:** CodeAlpha AI Internship - Task 1

## Project Description
Python application that translates English text to Urdu language using MyMemory API. Works completely on Android phone.

## How To Run On Phone
1. Install Pydroid 3 from Play Store
2. Copy translator.py code
3. Click Run button
4. Enter English text, get Urdu translation

## Technologies Used
- Python 3
- urllib.request (no external library needed)
- MyMemory Translation API
- Pydroid 3
